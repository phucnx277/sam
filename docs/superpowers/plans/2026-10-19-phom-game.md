# Phỏm Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full support for the Northern Vietnamese "Phỏm" card game alongside "Sâm" with table-level game selection, complete Wikipedia rules (Ăn, Bốc, Hạ phỏm, Gửi bài, Tời bài/Né hạ/Thêm vòng, Ù/Ù tròn/Ù khan, Móm, Đền 3 cây), and configurable chip multiplier.

**Architecture:** Extend `Table`, `Game`, and `GamePlayer` ambient types with optional Phỏm fields and isolate all Phỏm rules, meld combinatorics, turn phases, and chip calculations in `src/logic/phom.ts`. Wire Phỏm actions into `src/logic/game.ts` and `src/logic/table.ts`, and update table creation and gameplay UI components to render Phỏm-specific controls, Nọc, melds, discards, and rules.

**Tech Stack:** React 19, TypeScript, Vite 7, Tailwind CSS v4, Zustand.
